# dsh-universal-provider

**Подключите любой AI к DeepSeek Harness, вписав всего два поля.**

Устали от инструкций на десять шагов, где нужно выбрать протокол, найти ID провайдера, вручную прописать модели и не перепутать заголовки? Этот плагин решает проблему.

Вы вводите **адрес API** и **ключ**. Всё. Плагин сам разбирается, с кем имеет дело, и подключает провайдера.

---

## Зачем это нужно

В DeepSeek Harness можно подключить сторонние AI, но обычно для этого надо:

- знать, какой у провайдера протокол (OpenAI? Anthropic? ещё какой-то?),
- придумать уникальный ID,
- вручную вписать список моделей,
- надеяться, что ничего не перепутали.

Этот плагин убирает всё это. Он делает пробный запрос к вашему адресу, смотрит, как сервер отвечает, и сам выбирает нужный протокол. Вам остаётся только вставить ссылку и ключ.

---

## Что поддерживается

Практически всё, что существует на рынке:

- **Anthropic** (Claude)
- **DeepSeek**
- **Qwen** (через DashScope)
- **Grok** (xAI)
- **OpenRouter**
- **Groq**
- **Together AI**
- **Ollama** (локально)
- **LM Studio** (локально)
- **vLLM**
- **Любые прокси и шлюзы** вроде `https://api.какой-то-сервис.shop/v1`
- **Свои собственные серверы** с OpenAI-совместимым API

Если сервис вообще существует и умеет отвечать на запросы по HTTP — скорее всего, плагин его подключит.
